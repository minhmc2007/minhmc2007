# Minh (minhmc2007)

Developer from Vietnam. I mostly work on Python tools, Android modding (specifically Samsung dynamic partitions and budget devices), and small desktop utilities. I also maintain Legacydroid, my own custom ROM.

---

### Projects

- **[Custom-Super-Maker](https://github.com/minhmc2007/Custom-Super-Maker)**  
  GitHub Actions workflow to unpack, modify, and repack Samsung dynamic `super.img` partitions without needing a local Linux install. Built for flashing GSIs and custom ROMs on budget Samsung devices.

- **[AniCli Flutter](https://github.com/minhmc2007/AniCli-Flutter)**  
  A Flutter desktop GUI frontend for `ani-cli`.

- **[Blue-Archive-Linux](https://github.com/minhmc2007/Blue-Archive-Linux)**  
  Custom Arch-based Linux setup themed around Blue Archive. *(Standalone project, not KivotOS).*

- **[Tako](https://github.com/minhmc2007/Tako)**  
  Minimal scripting language written in C for embedded targets, toy OS development, and learning interpreter internals.

- **[UBT (Unity Bundle Tool)](https://github.com/minhmc2007/UBT)**  
  Python script to extract and repack Unity asset bundles.
